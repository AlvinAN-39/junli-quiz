## 1. 快速开始

### Windows 11
1. 双击 `dist\军理刷题.html`（用 Edge 或 Chrome 打开即可）。
2. 想变成桌面应用：打开后点浏览器右上角 `…` → **应用** → **安装此站点为应用**
   （或地址栏右侧的「安装」图标）。之后从开始菜单就能直接启动，独立窗口、可离线。
3. 快捷键：`1`~`9` 选选项、`Enter` 提交/下一题、`←`/`→` 翻题、`F` 收藏、`S` 搜索、`Esc` 回首页。

### iPhone ✅ 推荐：放到免费网址，以后完全不用电脑

> **先说清楚：iOS 无法可靠地运行本地 `.html` 文件。**
> 「文件」App 只给**只读预览**、不跑脚本；即使勉强「用 Safari 打开」，
> `file://` 协议下苹果也**禁止网页保存数据** —— 错题本和进度会存不住。
> 所以 iPhone 上要真正好用，必须让 App 跑在一个 **http/https 网址**上。
> （参考：[How to open an HTML file on iPhone](https://docs.vela.partners/blog/how-to-open-html-file-on-iphone)）

**A. 放到免费网址（推荐，用一次以后永远不用电脑）**

1. 把 **`dist\军理刷题-网页版.zip`** 发到 iPhone（微信/邮件/AirDrop 都行），存到「文件」App
2. iPhone 上用 Safari 打开 **`https://app.netlify.com/drop`** → 点上传区 → 选那个 zip → 等待
   得到形如 `https://xxx.netlify.app` 的网址（免费注册可永久保留）
3. Safari 打开该网址 → **分享** → **添加到主屏幕** → 完成

首次打开后会自动把页面与题库缓存到手机，之后**断网也能用**（Service Worker 离线缓存）。
备选免费托管：Cloudflare Pages、Vercel、GitHub Pages。详见 [Releases](https://github.com/AlvinAN-39/junli-quiz/releases)（`iPhone使用说明-不用电脑.txt` 随部署包一起发布）。

**B. 纯局域网（不想放公网时用；缺点是要电脑开着）**

1. Windows 上双击 **`dist\手机访问-双击我.bat`**（已自带 Python，无需另装）
2. 窗口里出现二维码 → iPhone 相机扫 → Safari 打开
3. **分享** → **添加到主屏幕**

两种方式互不冲突，各自独立保存进度；想同步就用 App 里的「导入/导出」JSON。

### 音效与震动（平台差异必须知道）
音效用 **Web Audio 实时合成**（零音频文件、零外部请求），并为不同操作区分语义：

| 操作 | 音效 | 震动 (ms) |
|------|------|-----------|
| 轻点（选选项 / 翻页 / 开关） | 1200Hz 短音 35ms | `10` |
| 确认（提交 / 开始练习考试 / 导入导出） | C5→G5 双音上行 | `12` |
| **答对** | C5-E5-G5 明亮三音上行 | `18` |
| **答错** | 330→220Hz 低沉双音下行 | `[28,45,28]` |
| 收藏 | 1568→2093Hz 上滑 | `14` |
| 展开/收起 | 1500Hz 22ms 极短音 | `8` |
| 完成（交卷 / 一轮结束） | C-E-G-C 四音琶音 | `[16,40,16,40,34]` |
| 危险操作（清空错题/成绩/数据） | 180→140Hz 低沉下滑 | `[40,60,40]` |

答对/答错由**真实判分结果**驱动（练习模式唯一判分出口 `submitPractice()` 回调一次），
不是由点击驱动；考试刻意**不逐题出声**，只在交卷出分时播完成琶音。
音量分**小 / 中 / 大**三档（在「导入 / 导出 → 声音与震动」里切换，默认中档），
等效增益为历史版本的 **2 / 3 / 4 倍**，其中**答对音再单独加权 1.3 倍**；
同一语义 60ms 去抖防连点噪声。切换档位会立刻试听一次。

#### 「全平台可用」是怎么做到的
iOS Safari 会把 **Web Audio 一并静音**（[WebKit bug 237322](https://wiki.webkit.org/show_bug.cgi?id=237322)），
所以单靠 Web Audio 做不到全平台。这里加了**双通道**：

1. **主通道**：Web Audio 合成音效（音色好、零文件体积）；
2. **保活通道**：一个**常驻循环的内联静音 `<audio>` 元素**（44.1kHz/单声道/16bit/0.05s，
   运行时按 RIFF 规范生成 data URL，约 5.9KB，无外部文件），
   `loop=true` / `muted=false` / `volume=0.001` / 首手势内 `play()`。

原理与 [swevans/unmute](https://github.com/swevans/unmute) 同源：让音频会话停留在
「媒体播放」类别，从而让 Web Audio 也绕过 iPhone 静音键。

> **如实说明：这是「兼容模式」，不是保证。** 我没有 iPhone 真机，无法验证具体 iOS 版本上
> 是否真的重分类成功；`volume=0.001` 是社区经验值；Apple 也在持续收紧此类绕过
> （例如 iOS 26.5 就封堵了网页触觉的 checkbox 技巧）。
> 即使无效，也只是「听不到声音」，**不影响任何功能**。
> 关闭音效开关时会暂停该音轨，避免一直占用系统音频会话。

#### iPhone 上没有网页震动
`navigator.vibrate()` 从未在 iOS 上提供；业界曾用隐藏 `<input type=checkbox switch>` +
程序化点击绕过，[Apple 已在 iOS 26.5+ 封堵](https://github.com/flarum/framework/issues/4694)。
所以震动在 iPhone 上静默跳过，**Android / Windows 桌面浏览器正常震动**。

两项都可在 **「导入/导出」→「声音与震动」** 里单独关闭（默认开），设置存 `jlx.settings.v1`。

### 答错后的关键词解析
答错时会在解析块下方额外展开一块内容（答对、未作答、背题模式都不显示）：

```
关键词解析
考点：国防的首要职能、基本职能和对外职能
[领空和领土不受侵犯] [防备和抵抗侵略] [确保国家领海] [基本职能] …
你选的选项为什么不对
B. 制止武装颠覆和分裂 — 教材中仅零星出现，不是本考点的规范表述。
```

数据侧由 `tools/gen_wrong_analysis.py` 生成三个字段（**只列用户实际选错的那几项**）：

| 字段 | 覆盖 | 来源 |
|------|------|------|
| `keyConcept` | 1159/1171（99%） | 从题干抽考点，并过**质量闸**（含数字/空格/疑问词一律置空，前端自动省略该行） |
| `keywords` | 1171/1171 | **优先取源材料里真实存在的术语**（正确选项、书名号/引号内专名、依据句），而不是猜词分段 |
| `distractorWhy` | 710/744 道选择题 | 按「教材语料中查不到 → 干扰项」「与正确项相近 → 易混淆」「否定题 → 属于考点但不符题意」等分类 |

**为什么关键词不能靠 n-gram 猜**：中文没有词边界，枚举窗口切出来的多是跨词碎片
（实测产出「的军」「象是」「防的」这类垃圾）。改成从「已知是词」的来源取词后，
关键词变成 `["战争论","克劳塞维茨"]`、`["尉缭子","兵者"]` 这样可读的结果。

### 两台设备之间同步进度
App 内「设置 → 导入/导出」：
- **导出**：生成 `军理刷题-进度-日期.json`（Safari 下退化为复制文本）。
- **导入**：选文件导入，或直接把 JSON 文本粘贴进文本框。
- iPhone 和 Windows 各导一次、互相导入，即可把错题本、收藏、成绩带过去。

### 关于「派生题」
你给的 4 份 PDF 里**没有判断题、也没有独立填空题**。为了让你能练这两种题型，
程序从单选题自动派生了一批（`section` 字段标为 `判断题（派生）` / `填空题（派生）`）：

- 取「题干恰好含一个 `____`、4 个选项」的单选题；
- 把**正确选项**填进空白 → 得到一句正确陈述（判断题：对）；
- 把某个**错误选项**填进空白 → 得到一句错误陈述（判断题：错）；
- 填空题 = 正确陈述原句，答案就是那个被挖掉的词。

派生题的解析里会注明「由单选题派生（原题 q-xxxx）」，方便你回溯核对。

### 已知不确定点（诚实说明，请务必读）
源 PDF 的**多选题答案**被排版压成了连续字母串（例如 `21-25ABCABDABCBCDABC`），
区间宽度与实际题数并不完全一致，存在**排版层面的固有歧义**。程序采用
「按区间宽度切段 + 段内平均摊派 2~4 个字母」的确定性策略解析，保证：

- 每道多选题**都有答案**，且答案长度合理（2~4 个选项）；
- 单选题、简答题的答案经交叉验证完全吻合（
  独立质检用「按题号重锚」法复核了编号连续的 9 个章节，单选答案 100% 成立）。

但**223 道多选题的答案集合无法从源文件唯一确定**——独立质检实测：
换一种同样合理的切分策略，约 **75%** 的多选题答案会变。因此：

> **204 道多选题带 `answerUncertain: true` 字段，App 会在题干下方显示
> 「⚠ 本题答案由原卷答案串自动解析，多选切分存在歧义，建议对照原卷核实」。**

另有 **21 道**经独立质检发现、并**逐条对照 `build/text` 源文件原文行号核实**后
人工校订（校订依据写进该题的 `explanation`，可追溯）：

| 类别 | 数量 | `answerUncertain` | 说明 |
|------|------|-------------------|------|
| 高置信校订 | 19 | `false` | 源卷/提纲原文直接列举了正确项，可判定 |
| 中等置信校订 | 2 | `true`（仍提示存疑） | 答案已修正，但题干术语口径无源句支撑，保留提示 |

### 关于「解析」
**每道题作答后都有解析**（1171/1171 = 100% 覆盖），并做成了**分行加标签**的形式：

#### 解析的「相关性」是怎么保证的
用户反馈过「解析和题目对不上」，为此**逐题核查了教材与提纲**（`tools/audit_corpus.py` / `fix_relevance*.py`）：

| 问题 | 修前 | 修后 |
|------|------|------|
| 依据句与题干**毫无共同实词**（讲的是别的事） | 168 道 | **3 道** |
| 依据句其实是教材的**思考题**（`军事思想有哪些作用?`） | 33 道 | **0** |
| 依据句含答案主干字面（最硬证据） | — | **645 道** |
| 语料规模（教材利用率） | 5,409 句 | **6,077 句** |

**核查教材时挖出的三个根本问题：**

1. **教材只被利用了 4,673/4,879 句。** `load_corpus()` 丢弃所有短于 12 字的片段，
   于是 `(1)服现役。`、`(2)服预备役。`、`(3)兵役制度。` 这类**正是填空题答案**的短句
   全部没进语料。`fix_relevance.build_extended_corpus()` 把全部片段补齐 →
   教材利用率提升到 6,000+ 句，**直接救回 51 道题的依据**。
2. **句子被排版切断。** 出现 `年7月7日…`（缺 1937）这类缺头碎片，
   导致**真正切题的句子在语料里根本不存在**。按形态识别并拼接后解决。
3. **教材思考题混进了正文。** `维护国家安全的基本原则有哪些?、总体国家安全观的内涵是什么?…`
   这类复习题列表靠与题干字面重合能拿到满分，是最强的假阳性来源，已整类排除。

**最终判据（简单且可复核）：依据句必须与题干有 ≥4 个连续汉字重合。**
实测这个判据下 631 道全部切题；而 <4 字的桶里集中了全部真正的错配
（数字枚举句、唱军歌句、法规颁发机关句…）。另留一个例外：
汉字重合 <4 但**答案内容字覆盖 ≥55%** 的保留（说明它确实在回答这道题，
只是题干问法不同，如「我国古代海防建设始于____」↔「古代海防工程建设始于明朝」）。

修正后：**655 道有依据句**（其中 645 道依据句含答案主干字面），
其余 516 道**如实说明「教材中未收录与该题直接对应的内容」**。

#### 选项乱序下的四处一致性（T18）
**已修复的 bug**：选项乱序只改了 `q.qa`（经 `dispLetterOf`），

修复落在**渲染层**（`sess.perm` 是每会话动态生成，数据层无法预排）：

| 函数 | 作用 |

## 7. 技术选择说明（为什么这么做）

- **为什么是纯静态网页，而不是 exe / App？**
  iPhone **无法安装**没有签名的第三方应用（TestFlight 或企业签名都不现实），
  而 Electron / Tauri 只能覆盖 Windows。纯静态 Web App 是唯一能同时满足
  「iPhone 能用」+「Windows 11 能用」+「离线」+「双击即用」的形态。
- **为什么单文件版要额外提供？**
  `file://` 打开时浏览器会禁用 Service Worker 和 `fetch`，所以要真正「双击即用」，
  必须把 CSS/JS/题库全部内联进一个 HTML。这就是 `dist\军理刷题.html`。
- **为什么不用 CDN？**
  断网可用、无外部依赖、不会被墙。所有图标都是手写内联 SVG。
- **数据存在哪？** 只存在你自己设备浏览器的 `localStorage`，不上传任何服务器。
