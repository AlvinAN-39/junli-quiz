# 截图回归场景清单（35 项）

本清单对应 `tests/screenshot_fix_test.mjs`。该套件是**长期回归资产，不是一次性探针**——它用真实浏览器覆盖用户两张截图（F5–F19）对应的界面行为，删掉它等于删掉这些场景唯一的代码化验证。

- 运行：`node tests/screenshot_fix_test.mjs`
- 依赖：Playwright（可选）与产物 `dist/军理刷题.html`（可选）。两者任一缺失即打印 `[SKIP]` 并**以退出码 0 结束**，因此 CI 不装 Playwright 也能绿。
- 输出：每项一行 `[PASS]` / `[FAIL]` / `[SKIP]`，末尾一行 JSON 摘要；退出码全部通过 0、存在失败非 0。
- 夹具注入：内存会话与存档**同时**写入。不要改成「先进生产入口 → 改 localStorage → hash 跳转」——应用离开路由时会把内存会话写回存档，覆盖夹具（这正是首跑 5 项假失败的根因）。
