### 派生题机制

原始资料里**没有判断题、也没有独立填空题**。为了让这两种题型可用，程序从单选题自动派生了一批
（`section` 字段标为 `判断题（派生）` / `填空题（派生）`，共 300 道）：

- 取「题干恰好含一个 `____`、4 个选项」的单选题；
- 把**正确选项**填进空白 → 得到一句正确陈述（判断题：对）；
- 把某个**错误选项**填进空白 → 得到一句错误陈述（判断题：错）；
- 填空题 = 正确陈述原句，答案就是被挖掉的那个词。

派生题的解析里会注明「由单选题派生（原题 q-xxxx）」，可回溯核对。

## 2. 解析与依据

每道题作答后都显示解析，结构为「正确答案 / 为什么 / 依据出处」。
字段 `explanationSrc` 标注依据等级，当前分布：

| `explanationSrc` | 含义 | 数量 |
|------------------|------|------|
| `textbook` | 教材原文 | 800 |
| `web` | 网页出处说明（网址另存 `webSourceUrl`） | 441 |
| `bank` | 题库自带说明 / 派生说明 | 267 |
| `manual` | 人工校订 | 10 |
| `template` | 未收录直接出处，如实说明 | 13 |

**覆盖情况**：1531题都有解析文字，13题的来源类型为template，14题尚缺具体的为什么段落。来源字段存在不等于已证明知识正确；题库自带说明也不能充当独立佐证。

### 依据相关性判据

依据句必须与题干有 **≥4 个连续汉字重合**；此外设一个例外：命中 **≥2 个题干实词** 也算通过
（这是为法规原文设的——法规是规范表述，题干往往是它的口语化改写，逐字重合天然就短）。
这个判据仅用于机器预筛。关键词重合既不能证明答案成立，也不能穷尽错配；否定设问、分类层次和时间范围必须另作语义核对。

## 3. 联网核查的收录规则

本地教材与提纲穷尽后仍缺依据的题，走联网核查补齐。**红线**：

- 必须真实联网检索；
- 必须给出可访问的 URL；
- 找不到就标 `found=false`；
- **绝不编造依据**。

**收录闸（两道）**：

1. **URL 权威性白名单** —— 只收法律法规数据库 / 政府 / 教育机构 / 权威官媒 / 官方出版社 / 经典文献库：
   `*.gov.cn`、`*.edu.cn`、`*.ac.cn`、`npc.gov.cn`、`moe.gov.cn`、`mod.gov.cn`、`people.com.cn`、
   `xinhuanet.com`、`news.cn`、`81.cn`、`cctv.com`、`qstheory.cn`、`studytimes.cn`、`chaoxing.com`、
   `ctext.org`、`wikisource.org`、`kepuchina.cn`、`cas.cn` 等。
   本轮还采用外国政府、军方及国际条约组织的一手资料，如 `navy.mil`、`gao.gov`、
   `congress.gov`、`mod.go.jp`、`ctbto.org`；其机构身份、具体主张和时间范围另行人工核对。
   **自媒体与商业门户一律不收**（百家号、搜狐、网易、新浪、今日头条等）——曾有一批依据内容正确、
   但引用的是转载页，被这条闸挡下，后来在原始权威页找到后重新收录。
2. **相关性** —— 依据句须与题干有 ≥4 个连续汉字重合，或命中 ≥2 个题干实词（见上一节）。

**静态复核结果**：0 条缺出处、0 条非法 URL。3条关键词相关性提示经人工阅读属于筛查误报：q-0389为《国防法》沿革，q-0865为C4ISR释义，q-0944为《战争论》所处时代。另有4条近似复述提示，不能据此判错，也不当作新增独立证明。网址格式通过不代表逐条联网验证已完成。
当前有441条web来源标记，出处说明存于explanationRef，网址存于webSourceUrl。数量只表示来源标签覆盖，不表示每题均已完成独立事实核查。

## 4. 多选题答案的固有歧义

原卷的多选题答案被排版压成了**连续字母串**（例如 `21-25ABCABDABCBCDABC`），区间宽度与实际题数
并不完全一致，存在排版层面的固有歧义。程序采用「按区间宽度切段 + 段内平均摊派 2~4 个字母」的
确定性策略解析，保证每道多选题都有答案、且答案长度合理。

独立质检用「按题号重锚」法交叉验证：单选题与简答题的答案与原卷 100% 吻合；
而多选答案集合无法从源文件唯一确定（换一种同样合理的切分策略，约四分之三的多选题答案会变）。

**当前状态**：2026-10-10本轮复核恢复2道多选题的answerUncertain提示（q-0128、q-0287），不以删除提示来获得零待定。另4道同源题的条例名称不完整，解析已说明待核。完整逐题检查与证据边界见文末。

## 5. 人工校订记录（节选）

部分多选题在原卷答案与教材/权威来源之间不一致，经逐条核对后人工修订（校订依据写进该题的
`explanation`，可追溯）。以下是几个典型例子：

| 题号 | 题干 | 修正为 | 依据 |
|------|------|--------|------|
| `q-0074` | 我国公民的国防义务 | `A、B、C、D` | 《宪法》第五十五条 + 同库简答答案 |
| `q-0083` | 2024 年新型军兵种结构布局 | `A、B、C、D` | 军事航天 / 网络空间 / 信息支援 / 联勤保障 |
| `q-0221` | 人民军队政治工作的原则 | `A、B、D` | 三大原则＝官兵一致 / 军民一致 / 瓦解敌军（原答案误选「权力平等」） |
| `q-0703` | 确保部队…… | `A、C、D` | 绝对忠诚、绝对纯洁、绝对可靠 |
| `q-0805` | 信息空间包括 | `A、C、D` | 电磁空间 / 网络空间 / 心理空间 |
| `q-0082` | 兵役制度的"两个结合" | `A、C` | 义务兵役制与志愿兵役制 + 民兵与预备役 |
| `q-0567` | "一带一路"倡议 | `A、B` | 丝绸之路经济带 + 21 世纪海上丝绸之路 |

**处置原则**：不能用「依据里提到某个选项」就机械补入答案——实测有反例：问「属于**非传统**安全」，
依据说「**军事冲突属于传统安全范畴**」，机械匹配会把「军事冲突」补进答案，正好相反。
因此这类题全部走**逻辑判断**（识别否定题干、排除项、正面清单），判为"正面清单"才补入。
