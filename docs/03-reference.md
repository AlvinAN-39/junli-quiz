## 2. 这本书在本软件中的三种作用

### 2.1 内容来源（章节框架）
题库的章节划分与教材一致：

| 教材章节 | 软件中的 `chapter` 字段 |
|----------|--------------------------|
| 第一章 中国国防 | 第一章中国国防 |
| 第二章 国家安全 | 第二章国家安全 |
| 第三章 军事思想 | 第三章军事思想 |
| 第四章 现代战争 | 第四章现代战争 |
| 第五章 信息化装备 | 第五章信息化装备 |

### 2.2 答案核校语料（关键用途）
教材全文被提取为纯文本（`build/text/1-textbook.txt`，约 **20.5 万中文字**），
作为**独立于题库本身的第三方语料**，用于：

1. 校验题目选项是否为教材中的规范表述；
2. 为「多选题答案存疑」的题提供人工复核依据；
3. 支撑 `tools/check_multi_answers.py` 的语义抽检
   （输出 `qa/multi-answer-audit.json`：被选为答案的选项在教材中命中率 64.6%，
   未选中选项 47.0%）。

### 2.3 多选题答案的人工校订依据
若干道多选题的答案由源答案串切分歧义导致错误，是**依据教材原文**逐条核对后校订的。
例如：

| 题号 | 题干 | 校订为 | 教材依据 |
|------|------|--------|----------|
| `q-0221` | 人民军队政治工作的原则 | `A、B、D` | 政治工作三大原则＝官兵一致、军民一致、瓦解敌军（原答案误选「权力平等」） |
| `q-0805` | 信息空间包括 | `A、C、D` | 信息空间＝电磁空间 + 网络空间 + 心理空间 |
| `q-0858` | 新概念武器按基本原理 | `A、B` | 定向能武器 + 动能武器 |
| `q-0083` | 2024 年新型军兵种结构布局 | `A、B、C、D` | 军事航天、网络空间、信息支援、联勤保障 |

校订表见 `tools/parse_questions.py` 中的 `CURATED_FIXES`（每条都写明依据），
可用 `python tools/eval_qa_candidates.py` 打印逐条对照。
